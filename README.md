# Управление IT-фирмой — доработка для «Ваш компьютерный мастер»

Инструкция для специалистов заказчика по начальной настройке и эксплуатации добавленного функционала (префикс **ВКМ_**).

Предприятие уже ведёт учёт в исходной конфигурации «Управление IT-фирмой». Ниже описаны действия, которые нужно выполнить в **рабочей** информационной базе после установки обновления конфигурации.

## Что добавлено

В конфигурацию добавлены две подсистемы в разделе **ВКМ добавленные объекты**:

| Блок | Назначение |
|------|------------|
| **Обслуживание клиентов** | Планирование выездов специалистов, учёт выполненных работ, массовое выставление актов |
| **Расчёт управленческой зарплаты** | Начисление и выплата зарплаты, премии, график отпусков, отчёты по персоналу |

Новые объекты не заменяют типовой учёт продаж и закупок — они дополняют его.

## 1. Обновление конфигурации

Выполняет администратор 1С.

1. Создайте **резервную копию** информационной базы.
2. Загрузите обновлённую конфигурацию из поставки разработчика (файл `.cf` / выгрузка из 1С:EDT).
3. Выполните **обновление конфигурации базы данных** (Конфигуратор → Конфигурация → Обновить конфигурацию базы данных).
4. Запустите **1С:Предприятие** в режиме администратора и дождитесь завершения отложенного обновления ИБ (если оно запускается).
5. Убедитесь, что в интерфейсе появился раздел **ВКМ добавленные объекты**.

> Обработка **ВКМ начальное заполнение данных** предназначена только для **демонстрационных** баз. В рабочей базе её не запускайте — она создаёт тестовые организации, контрагентов и документы.

## 2. Настройка прав доступа

Права настраиваются через подсистему **Управление доступом** (БСП). В конфигурацию добавлены поставляемые **профили групп доступа**:

| Профиль | Кому назначать | Основные возможности |
|---------|----------------|----------------------|
| **Специалист** (`ВКМ_Специалист`) | IT-специалисты | Закрытие заявок на обслуживание, отчёт «ВКМ выработка специалистов» |
| **Менеджер** (`ВКМ_Менеджер`) | Менеджеры по работе с клиентами | Планирование обслуживания, работа с контрагентами и договорами |
| **Бухгалтер ИТ-фирмы** (`ВКМ_БухгалтерИТФирмы`) | Бухгалтерия | Массовое создание актов, реализация товаров и услуг, отчёт по актам |
| **Кадровик-расчетчик** (`КадровикРасчетчик`) | Кадровая служба / расчётчик | Зарплата, премии, выплаты, график отпусков, отчёты по персоналу |

### Порядок настройки

1. Откройте **Администрирование → Настройки пользователей и прав → Группы доступа**.
2. Обновите поставляемые профили (команда **Обновить поставляемые профили** или аналог в вашей версии БСП).
3. Создайте группы доступа по образцу (например: «ВКМ Специалисты», «ВКМ Менеджеры», «ВКМ Бухгалтерия», «ВКМ Кадровики») и укажите соответствующий профиль.
4. Включите пользователей в нужные группы (**Пользователи** в справочнике должны быть связаны с учётными записями ИБ).
5. Пользователю с полными правами оставьте профиль **Администратор** (или отдельную группу для настройки констант и регламентных заданий).

После изменения прав пользователям необходимо **перезайти** в программу.

## 3. Заполнение констант и справочников

Константы доступны в разделе **ВКМ добавленные объекты** (или через поиск в интерфейсе «Все функции»).

| Константа | Обязательность | Назначение |
|-----------|----------------|------------|
| **Номенклатура абонентская плата** | Обязательно | Номенклатура услуги для строки абонентской платы в реализации |
| **Номенклатура работы специалиста** | Обязательно | Номенклатура услуги для оплаты работ специалиста по часам |
| **Токен управления телеграм-ботом** | По желанию | Токен бота Telegram для оповещений |
| **Идентификатор группы телеграм для оповещения** | По желанию | ID группы/чата, куда бот отправляет сообщения |

### Номенклатура

1. В справочнике **Номенклатура** создайте (или выберите существующие) две позиции услуг, например:
   - «Абонентское обслуживание»;
   - «Работы специалиста (почасовая оплата)».
2. Укажите их в константах **Номенклатура абонентская плата** и **Номенклатура работы специалиста**.

Без заполненных констант не работают:

- автозаполнение документа **Реализация товаров и услуг**;
- обработка **ВКМ массовое создание актов**;
- отчёт **ВКМ анализ выставленных актов**.

## 4. Настройка договоров абонентского обслуживания

Для каждого клиента с абонентским обслуживанием:

1. Откройте справочник **Договоры контрагентов**.
2. Создайте или откройте договор.
3. Укажите вид договора **ВКМ абонентское обслуживание**.
4. Заполните реквизиты (появляются при выборе этого вида):
   - **Дата начала действия**;
   - **Дата окончания действия**;
   - **Сумма абонентской платы** (ежемесячная, может быть 0);
   - **Стоимость часа работы** (ставка для расчёта суммы по выполненным работам).

Документ **Обслуживание клиента** можно проводить только по договору этого вида и только если дата работ попадает в период действия договора.

## 5. Условия оплаты сотрудников

Перед начислением зарплаты и проведением обслуживания специалистами необходимо задать условия оплаты.

Регистр сведений: **ВКМ условия оплаты сотрудников** (раздел **ВКМ добавленные объекты**).

Для каждого сотрудника (элемент справочника **Пользователи**) создайте запись:

| Поле | Описание |
|------|----------|
| **Период** (месяц) | С какого месяца действуют условия |
| **Сотрудник** | Пользователь — сотрудник компании |
| **Оклад** | Фиксированная часть зарплаты |
| **Процент от работ** | Доля от суммы работ, оплаченных клиентом (для специалистов; для административного персонала можно указать 0) |

**Важно:**

- без записи в регистре документ **Обслуживание клиента** не проведётся (для указанного специалиста);
- без условий оплаты документ **ВКМ начисление заработной платы** выдаст ошибку при расчёте;
- при изменении оклада или процента создавайте новую запись с новым месяцем (регистр периодический).

## 6. Производственный календарь

Для расчёта оклада по рабочим дням используется регистр сведений **ВКМ календарь** (пн–пт — рабочие дни, сб–вс — выходные).

Перед первым начислением зарплаты календарь должен быть заполнен **на каждый год**, в котором ведутся расчёты.

### Заполнение (выполняет администратор)

Отдельной кнопки в интерфейсе нет. Администратор выполняет однократно для нужных лет (например, 2025 и 2026):

1. Откройте **Все функции → Консоль кода** (или выполните код иным способом, доступным администратору).
2. Выполните:

```bsl
ВКМ_РасчетЗарплаты.ЗаполнитьКалендарь(2025);
ВКМ_РасчетЗарплаты.ЗаполнитьКалендарь(2026);
```

Подставьте актуальные годы. Процедуру повторяйте в начале каждого нового года.

При необходимости отдельные даты (праздники) можно скорректировать вручную в списке регистра **ВКМ календарь**.

## 7. Оповещения в Telegram (необязательно)

Если нужны уведомления специалистам о новых и изменённых заявках:

1. Создайте Telegram-бота через [@BotFather](https://t.me/BotFather) и получите **токен**.
2. Добавьте бота в группу специалистов и узнайте **идентификатор чата** (числовой `chat_id`).
3. Заполните константы **Токен управления телеграм-ботом** и **Идентификатор группы телеграм для оповещения**.
4. На сервере 1С должно быть разрешено **исходящее HTTPS-соединение** с `api.telegram.org`.
5. Включите регламентное задание **ВКМ отправка уведомлений телеграм**:
   - **Администрирование → Обслуживание → Регламентные и фоновые задания**;
   - найдите задание, установите флажок **Использование**.

При записи документа **Обслуживание клиента** (создание или изменение даты, времени, специалиста) в очередь добавляется сообщение; регламентное задание отправляет его и удаляет из очереди.

Если константы не заполнены, документы работают штатно, но сообщения в Telegram не отправляются.

## 8. Повседневная работа пользователей

### Менеджер

1. **ВКМ добавленные объекты → Обслуживание клиентов → Обслуживание клиента → Создать**.
2. Укажите клиента, договор (абонентское обслуживание), специалиста, дату и плановое время, опишите проблему.
3. Запишите документ (проводить на этом этапе не обязательно).

### Специалист

1. Откройте назначенное **Обслуживание клиента**.
2. После выполнения работ заполните табличную часть **Выполненные работы**:
   - описание;
   - фактически потрачено часов;
   - часы к оплате клиенту.
3. Приложите скан листа учёта рабочего времени (команда присоединённых файлов).
4. **Проведите** документ.

При проведении рассчитываются суммы для клиента (по ставке договора) и для специалиста (по проценту из условий оплаты).

### Бухгалтер

**Вариант А — одна реализация вручную**

1. **Продажи → Реализация товаров и услуг → Создать**.
2. Укажите организацию, контрагента, договор абонентского обслуживания, дату (конец месяца).
3. Нажмите **Заполнить** — табличная часть заполнится абонентской платой и работами за месяц.
4. Проведите документ, распечатайте акт об оказанных услугах.

**Вариант Б — массовое создание (начало месяца)**

1. **ВКМ добавленные объекты → ВКМ массовое создание актов**.
2. Укажите **Период** (месяц, за который выставляются акты).
3. **Заполнить** — в таблицу попадут все действующие абонентские договоры; для договоров, по которым реализация уже есть, ссылка отобразится в колонке реализации.
4. **Создать реализации** — программа создаст и проведёт документы за договоры без реализации.
5. Ошибки по отдельным договорам выводятся в окне сообщений; успешно созданные документы — в таблице обработки.

### Кадровик-расчетчик

Рекомендуемый порядок в конце месяца:

1. **ВКМ график отпусков** — в начале года: план отпусков на год (анализ графика — команда на форме документа).
2. **ВКМ начисление заработной платы** — указать месяц, добавить сотрудников, провести (оклад, % от работ, отпускные, НДФЛ 13%).
3. **ВКМ начисление фиксированной премии** — при необходимости разовые премии.
4. **ВКМ выплата заработной платы** — заполнить по остаткам взаиморасчётов с сотрудниками, провести.

## 9. Отчёты

Все отчёты — в разделе **ВКМ добавленные объекты** (часть — в подсистеме **Обслуживание клиентов**).

| Отчёт | Кто использует | Назначение |
|-------|----------------|------------|
| **ВКМ выработка специалистов** | Специалист, кадровик | Часы и сумма % от работ за период |
| **ВКМ анализ выставленных актов** | Бухгалтер | Сверка сумм к выставлению и фактически выставленных по работам |
| **Расчёты с сотрудниками** | Кадровик | Начисления, выплаты, задолженность |
| **Расход запланированных отпусков** | Кадровик | План и факт отпусков за год |

Во всех отчётах с периодом используется параметр **Стандартный период**.

## 10. Проверка готовности к работе

Перед передачей в эксплуатацию убедитесь:

- [ ] Конфигурация обновлена, раздел **ВКМ добавленные объекты** виден в интерфейсе.
- [ ] Профили групп доступа обновлены, пользователям назначены роли **Специалист**, **Менеджер**, **Бухгалтер ИТ-фирмы**, **Кадровик-расчетчик** по должностям.
- [ ] Заполнены константы номенклатуры абонентской платы и работ специалиста.
- [ ] По клиентам созданы договоры вида **ВКМ абонентское обслуживание** с периодом и ставками.
- [ ] Для всех сотрудников заданы **условия оплаты** на текущий месяц.
- [ ] Заполнен **ВКМ календарь** на текущий и следующий год.
- [ ] (Опционально) Настроен Telegram и включено регламентное задание отправки.
- [ ] Тестовый цикл: менеджер создал обслуживание → специалист провёл → бухгалтер сформировал реализацию → кадровик начислил зарплату.
